# ScDomi.github.io

GitHub Pages surface for `scryx` / ScDomi.

Not a classic blog. The homepage is an artifact-first interface: projects, systems, models, and visual identity.

## Structure

- `index.html` — main surface
- `about.html` — background page
- `contact.html` — contact page
- `assets/style.css` — site styling
- `assets/brand/` — scryx visual assets
