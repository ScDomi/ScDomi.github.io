Building a Small Local Agent OS

DomiNet started as a rough idea and turned into a local agent system with a central brain, specialized roles, task state, messages, reviews, context files, and a first browser dashboard.

2026-06-02 5 min read Agent Systems

From Idea to Working System

Today was one of those days where a loose idea turned into something concrete. Not a vague plan for some future system, but actual files, tasks, agents, a message bus, and a dashboard.

The idea behind DomiNet is simple: treat AI agents less like random chat prompts and more like a small local operating system. There is a central brain, several specialized agents, and a clear workflow: a task comes in, agents work on it, responses land in an inbox, and the central brain reviews what happened.

The Task Lifecycle

The first important part was the task lifecycle. DomiNet can create tasks, run agents through a cycle, store their outputs, review inbox messages, and mark work as done or blocked.

That sounds dry, but it is the core of the system. Without a lifecycle, there is no real agent system. There is only chat output with a nicer name. Now there is state, priority, history, and a path from request to review.

The Command Center

The next step was the CLI. Instead of remembering several separate scripts, the system now has one main command surface:

python3 agent-system/scripts/dominet.py status
python3 agent-system/scripts/dominet.py create
python3 agent-system/scripts/dominet.py run
python3 agent-system/scripts/dominet.py review
python3 agent-system/scripts/dominet.py close

That makes DomiNet feel less like an experiment folder and more like something that can actually be operated.

Roles and Context

The agents also became more structured. They are not just named Planner, Writer, or Messenger. They load role profiles from agents/*.md, so each agent has a clearer operating style.

Tasks can also include context files. That means an agent can work from relevant material instead of answering in empty space. It is a small step, but it makes the output much easier to trust and inspect.

Review Instead of a Black Box

One of the most useful additions was review --verbose. The central brain can now show not only what an agent answered, but also which role profile and context evidence shaped that answer.

This matters because agent systems need to be inspectable. If the workflow cannot be reviewed, improved, or debugged, it becomes a black box very quickly.

The First Dashboard

After the CLI came the dashboard path: first structured task lists, then a JSON data source, then a static HTML dashboard.

The dashboard now shows metrics, status distribution, tasks, inbox messages, outbox messages, and expandable task details. It also runs remotely through Tailscale, so it can be opened from a MacBook outside the local machine.

That turns DomiNet from a terminal-only project into something closer to a small control room.

Where It Stands

Right now, DomiNet is a local agent OS with a central brain, seven agent roles, a task system, a message bus, a CLI, context support, review mode, and a first dashboard.

It is not the final version of a personal AI system yet. But it is a real foundation: local, modular, inspectable, and easy to extend. That is the important part.

The Emergence Question

A good friend from university pushed an idea that makes this even more interesting: if many agent systems are trained, customized, and connected over time, maybe the important thing is not only the individual agent anymore.

The more interesting possibility is emergence. Specialized agents could start forming higher-level patterns through memory, repeated workflows, feedback loops, and coordination. Not just one smart assistant, but something closer to a super-agent: a system where useful structure appears out of many smaller chaotic interactions.

That is still speculative, but it is exactly the kind of idea that makes agent systems feel worth building. The goal is not only automation. It is finding patterns in the chaos and turning them into a working intelligence layer.

Next Step

The next visual step is a more dynamic dashboard: a central brain node, agent nodes around it, live-looking connections, message pulses, and task clusters.

Short version: today turned "I want an agent system" into a working DomiNet v0.2.x prototype. That is a solid start.
