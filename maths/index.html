A mathematical lab for real interactive systems: equations first, visualization second. The first exhibit is a numerically integrated Lorenz attractor — not a decorative loop.

live system / differential equations

Lorenz Attractor

integrating…
governing equations dx/dt = σ(y − x) dy/dt = x(ρ − z) − y dz/dt = xy − βz

The curve is integrated with RK4 from the Lorenz system. Tiny changes in the initial state eventually separate, even though the trajectory stays inside the same butterfly-shaped attractor.

Drag to rotate. Scroll/pinch to zoom. The bright head is the moving state; the glowing segment is the evolving recent trail.
