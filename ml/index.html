chapter 01 / boundary

a classifier is geometry pretending to be judgment.

Logistic regression computes a score, squeezes it through σ, then draws the 50% contour. The line is where the model is exactly unsure. On these crescents it keeps a pink-ringed minority it can never reach — fixing that is chapter 03’s job.

z = w₁x + w₂y + b p = σ(z) = 1 / (1 + e⁻ᶻ) boundary: p = 0.5 ⇒ z = 0
