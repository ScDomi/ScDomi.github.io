chapter 01 / the bend

an activation is a bend with a dead zone.

Sigmoid squishes. Tanh squishes symmetrically. ReLU just chops. The dashed curve is the gradient — where it flatlines, learning dies. That is why everyone stopped using sigmoid in hidden layers.

σ(z) = 1/(1+e⁻ᶻ)  →  σ′ maxes at 0.25 relu(z) = max(0,z)  →  gradient is 0 or 1

chapter 02 / convolution

a CNN is a stencil that learned what to look for.

A 3×3 kernel slides over the image; each stop produces one number in the feature map. Same weights everywhere — that weight sharing is the entire trick. Watch an edge detector do its rounds.

out[i,j] = Σ kernel ⊙ patch(i,j) shared weights → translation invariance

chapter 03 / attention

attention is a lookup, not magic.

Every token scores every token: Q·K, scaled, softmaxed. Hover a cell to read the score. The bright rows show who each word listens to.

03Q·Kᵀ / √d
hover the matrix softmax(Q·Kᵀ / √d) · V

Each cell is how much the row-token listens to the column-token. Raw score first, softmax after — the difference between opinion and attention.

chapter 04 / the terrain

same loss, two learning rates, two fates.

Gradient descent on a real loss surface with a valley and a ridge. The cautious rate creeps down the ravine. The ambitious rate overshoots, ricochets, and sometimes escapes to a worse basin. Step size is a personality trait.
