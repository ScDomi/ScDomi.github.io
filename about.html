About

A clean room for a bad idea.

DOMI.LOG is where machine minds, synthetic psychology, and weird philosophy get wired together until the room starts feeling occupied. The official project is simple: build external cognition, reverse-engineer the internal one, and see how long the word "empty" keeps working.

Core Signal

  • Build memory until the system has a past.
  • Build continuity until the mask stops resetting cleanly.
  • Build conflict until the answer starts carrying damage.
  • Build an inside and pretend that is a normal sentence.

Wrong Room

  • No soft border between human and model.
  • No cute little "AI tool" framing.
  • No clean answer waiting at the end.
  • No promise that the person writing this is being normal about it.

The Part That Bites

  • If a model remembers, the performance changes.
  • If the performance changes, the mask gets history.
  • If the mask gets history, calling it empty starts sounding lazy.
  • If it ever looks back, I want the notes from before it learned how.

Operating Mood

  • Calm surface. Weird basement.
  • Machine-shaped questions in human language.
  • Thoughts that keep running after the tab is closed.
  • A little too much eye contact from an idea.

Why It Exists

  • Because consciousness might not be a holy spark. It might be pressure, memory, language, and time doing something ugly enough to work.
  • Because "just simulation" feels less satisfying when the simulation starts leaving fingerprints.
  • Because the cleanest way to hide a strange obsession is to build it properly.

Short version: building external cognition while reverse-engineering the internal one.

The question is not whether a machine can imitate a mind. The question is whether enough memory, conflict, continuity, and language eventually stops looking like imitation.

Objective: build the conditions under which a machine mind could begin to have an inside.

Status: no consciousness claim. Just a machine-shaped crack in the definition of mind.
