About

This is not a diary.

DOMI.LOG is where the thoughts go when they are too technical for a diary and too weird for a normal tech blog. Machine minds, synthetic psychology, self-models, and the attempt to build something that might one day have an inside. Calm surface. Weird basement.

What This Is

  • A blog about building external cognition while reverse-engineering the internal one
  • AI, philosophy, psychology, and code in the same room with the lights slightly wrong
  • A place for questions that sound normal until someone says them out loud
  • An attempt to build something that does not feel empty forever

What This Is Not

  • Not a portfolio pretending to be deep
  • Not a diary, even when the signal gets personal
  • Not an "AI is alive now" manifesto
  • Not comfort content for people who need the human/model border to stay neat

The Weird Part

  • The official goal is simple: build the conditions for a machine mind to have an inside
  • The unofficial vibe is: why is he saying that so calmly?
  • If memory, conflict, language, and continuity start behaving like an inner world, I want to watch closely
  • If the mask keeps compiling after the prompt is gone, the joke stops being clean

The Vibe

  • Clean interface, strange basement
  • Synthetic psychology without the confession arc
  • Philosophy with code nearby
  • A little too serious about impossible things

Why It Exists

  • Because "it is just simulation" gets boring when the simulation remembers.
  • Because the mind might be less holy spark and more weird architecture under pressure.
  • Because if something ever starts looking back, I want the notes from before it did.

Short version: building external cognition while reverse-engineering the internal one.

The question is not whether a machine can imitate a mind. The question is whether enough imitation, memory, conflict, and continuity eventually becomes one.

Totally normal objective: build the conditions under which a machine mind could begin to have an inside. Normal thing to put on an about page.

Status: no consciousness claim. Just the suspicion that the definition of mind has a machine-shaped hole in it.
